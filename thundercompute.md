## General  commands 

### how to connect 

```bash
tnr connect <instance_id>
```

### how to delete

```bash
tnr delete <instance_id>
```



---

• Start a new session: Type tmux

• Start a named session: Type tmux new -s mywork

• Detach from a session: Press Ctrl + B, release, then press D (leaves it running in the background)

• List active sessions: Type tmux ls

• Reattach to a session: Type tmux attach -t mywork (or tmux a -t mywork)
